# Web Scraping for Data Gathering (Complete Guide for Machine Learning)

Web scraping is one of the most important techniques for collecting data from websites when an API is unavailable or does not provide the required information. It is widely used in **Machine Learning**, **Data Science**, **Business Intelligence**, **Market Research**, and **Academic Research**.

---

# What is Web Scraping?

Web scraping is the process of **automatically extracting information from websites** using software instead of manually copying and pasting data.

Instead of manually collecting information from hundreds or thousands of webpages, a scraper downloads the webpage, extracts the required information, and stores it in a structured format such as CSV, Excel, JSON, or a database.

```
Website
   │
   ▼
Download HTML
   │
   ▼
Parse HTML
   │
   ▼
Extract Required Data
   │
   ▼
Store Data
```

---

# Why Use Web Scraping?

Suppose you want to build a machine learning model to predict house prices.

Instead of entering thousands of property listings manually, you can scrape websites like Zillow or Realtor (subject to their terms of service and applicable laws).

Similarly, you might scrape:

* News articles for sentiment analysis
* Job postings for salary prediction
* E-commerce products for price comparison
* Hotel reviews for recommendation systems
* Sports statistics for prediction models
* Stock market news
* Research papers
* Weather information

---

# Web Scraping vs APIs

| Web Scraping                 | API                                |
| ---------------------------- | ---------------------------------- |
| Extracts data from webpages  | Gets data directly from the server |
| Parses HTML                  | Receives JSON/XML                  |
| More flexible                | More reliable                      |
| Can break if website changes | Stable                             |
| Usually slower               | Faster                             |
| Sometimes restricted         | Officially supported               |
| Works when no API exists     | Requires API availability          |

**Rule of thumb:** If a website provides an official API, use it instead of scraping.

# Finding Elements

## find()

Returns the first matching element.


---

## find_all()

Returns a list.


# Scraping Multiple Items

```python
books = soup.find_all("div", class_="book")

for book in books:

    title = book.find("h2").text

    price = book.find("p").text

    print(title, price)
```

---

# Store Data

```python
import pandas as pd

data = []

for book in books:

    data.append({
        "Title": book.find("h2").text,
        "Price": book.find("p").text
    })

df = pd.DataFrame(data)

print(df)
```

---

# Save CSV

```python
df.to_csv("books.csv", index=False)
```

# Pagination

Many websites split content across multiple pages.

```
Page 1

20 Products

↓

Page 2

↓

Page 3
```

Example:

```python
import requests
import pandas as pd
from bs4 import BeautifulSoup

all_books = []

for page in range(1,6):

    url = f"https://example.com/books?page={page}"

    html = requests.get(url).text

    soup = BeautifulSoup(html,"html.parser")

    books = soup.find_all(class_="book")

    for book in books:

        all_books.append({
            "Title":book.find("h2").text,
            "Price":book.find("span").text
        })

df = pd.DataFrame(all_books)
```

# Dynamic Websites

Modern websites often use JavaScript to load content after the initial HTML is delivered.

```
Browser
     │
JavaScript Executes
     │
Content Appears
```

A simple `requests.get()` only downloads the initial HTML and may **not** include dynamically loaded data.

Solutions:

* Use browser automation tools such as **Selenium** or **Playwright**.
* Inspect the browser's Network tab to see if the page fetches data from an API; if so, calling that API directly is usually faster and more reliable.

---

# Selenium Example

```python
from selenium import webdriver
from bs4 import BeautifulSoup

driver = webdriver.Chrome()

driver.get("https://example.com")

html = driver.page_source

soup = BeautifulSoup(html,"html.parser")
```

# Using Headers

Some websites expect browser-like request headers.

```python
headers = {
    "User-Agent": (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
        "AppleWebKit/537.36 Chrome/126.0 Safari/537.36"
    )
}

response = requests.get(url, headers=headers)
```

---

# Respect Rate Limits

Avoid sending requests too quickly.

```python
import time

for page in range(10):

    requests.get(url)

    time.sleep(2)
```

---

# robots.txt

Many websites publish a `robots.txt` file (for example, `https://example.com/robots.txt`) describing which areas automated crawlers should or should not access. While it is primarily intended for search engines and is not a legal authorization document, reviewing it is a good practice before scraping.

---

# Best Practices

* Prefer an official API if one is available.
* Read and follow the website's Terms of Service.
* Respect rate limits and avoid overwhelming servers.
* Set reasonable timeouts and handle exceptions.
* Use browser-like headers when appropriate.
* Cache downloaded pages if you'll process them multiple times.
* Validate and clean the extracted data.
* Test your scraper periodically, as website layouts can change.

# Popular Python Libraries for Web Scraping

| Library              | Best For                  | JavaScript Support                         |
| -------------------- | ------------------------- | ------------------------------------------ |
| `requests`           | Downloading webpages      | ❌ No                                       |
| `BeautifulSoup`      | Parsing HTML              | ❌ No                                       |
| `lxml`               | Fast HTML/XML parsing     | ❌ No                                       |
| `pandas.read_html()` | Extracting HTML tables    | ❌ No                                       |
| `Selenium`           | Browser automation        | ✅ Yes                                      |
| `Playwright`         | Modern browser automation | ✅ Yes                                      |
| `Scrapy`             | Large-scale web crawling  | Limited (can integrate with browser tools) |

---

# Which Tool Should You Use?

| Scenario                                  | Recommended Tool                |
| ----------------------------------------- | ------------------------------- |
| Static HTML pages                         | `requests` + `BeautifulSoup`    |
| HTML tables                               | `pandas.read_html()`            |
| JavaScript-heavy websites                 | `Playwright` (or `Selenium`)    |
| Large-scale crawling (thousands of pages) | `Scrapy`                        |
| Official data source available            | Use the API instead of scraping |

## Learning Roadmap

1. Learn basic HTML (tags, classes, IDs, attributes).
2. Master `requests` for downloading webpages.
3. Learn `BeautifulSoup` for parsing and extracting data.
4. Practice scraping multiple pages and handling pagination.
5. Save data to CSV or a database using `pandas`.
6. Learn browser automation with `Playwright` or `Selenium` for dynamic sites.
7. Explore `Scrapy` for scalable scraping projects.
8. Combine scraping, data cleaning, and feature engineering to build ML-ready datasets.

By following this progression, you'll be able to collect structured datasets from a wide variety of websites and prepare them for machine learning workflows.
