# Web Scraping for Data Gathering (Complete Guide for Machine Learning)

Web scraping is one of the most important techniques for collecting data from websites when an API is unavailable or does not provide the required information. It is widely used in **Machine Learning**, **Data Science**, **Business Intelligence**, **Market Research**, and **Academic Research**.

---

# What is Web Scraping?

Web scraping is the process of **automatically extracting information from websites** using software instead of manually copying and pasting data.

Instead of manually collecting information from hundreds or thousands of webpages, a scraper downloads the webpage, extracts the required information, and stores it in a structured format such as CSV, Excel, JSON, or a database.

```
Website
   │
   ▼
Download HTML
   │
   ▼
Parse HTML
   │
   ▼
Extract Required Data
   │
   ▼
Store Data
```

---

# Why Use Web Scraping?

Suppose you want to build a machine learning model to predict house prices.

Instead of entering thousands of property listings manually, you can scrape websites like Zillow or Realtor (subject to their terms of service and applicable laws).

Similarly, you might scrape:

* News articles for sentiment analysis
* Job postings for salary prediction
* E-commerce products for price comparison
* Hotel reviews for recommendation systems
* Sports statistics for prediction models
* Stock market news
* Research papers
* Weather information

---

# Web Scraping vs APIs

| Web Scraping                 | API                                |
| ---------------------------- | ---------------------------------- |
| Extracts data from webpages  | Gets data directly from the server |
| Parses HTML                  | Receives JSON/XML                  |
| More flexible                | More reliable                      |
| Can break if website changes | Stable                             |
| Usually slower               | Faster                             |
| Sometimes restricted         | Officially supported               |
| Works when no API exists     | Requires API availability          |

**Rule of thumb:** If a website provides an official API, use it instead of scraping.

# Dynamic Websites

Modern websites often use JavaScript to load content after the initial HTML is delivered.

```
Browser
     │
JavaScript Executes
     │

```

A simple `requests.get()` only downloads the initial HTML and may **not** include dynamically loaded data.

Solutions:

* Use browser automation tools such as **Selenium** or **Playwright**.
* Inspect the browser's Network tab to see if the page fetches data from an API; if so, calling that API directly is usually faster and more reliable.

* Prefer an official API if one is available.
* Read and follow the website's Terms of Service.

### Why `requests.get()` doesn't work

When you do

```python
import requests

url = "https://www.ambitionbox.com/list-of-companies?campaign=desktop_nav&page=1"

response = requests.get(url)

print(response.status_code)
print(response.text[:500])
```

the server doesn't just look at your URL. It also checks things like:

* User-Agent
* Cookies
* JavaScript execution
* Browser fingerprint
* TLS fingerprint
* Session behavior

A normal browser passes these checks, but Python's `requests` library does not, so the site identifies it as automated traffic. ([DEV Community][2])

# Step 1: See what you're actually getting

First check:

```python
import requests

url = "https://www.ambitionbox.com/list-of-companies?campaign=desktop_nav&page=1"

response = requests.get(url)

```

If you see something like

```

```

or

```
Just a moment...
```

or

```
Sorry, you have been blocked
```

then you're not receiving the real webpage.

# Step 2: Try browser headers

Sometimes adding browser headers works.

```python
import requests

headers = {
    "User-Agent":
    "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/137.0 Safari/537.36"
}

response = requests.get(
    url,
    headers=headers,
    timeout=20
)

print(response.status_code)
```

For AmbitionBox, this is usually **not enough**. ([Stack Overflow][1])

---

# Step 3: Use a Session

```python
session = requests.Session()

session.headers.update({
    "User-Agent":
    "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/137.0 Safari/537.36"
})

response = session.get(url)

print(response.status_code)
```

Again, this often still fails because the protection is more advanced. ([volcengine.com][3])

---

# Step 4: Inspect the Network tab (Recommended)

Open the page in Chrome.

Press **F12** → **Network**

Refresh the page.

Look for requests under **Fetch/XHR**.

Many modern websites don't render all the data directly in the HTML. Instead, the browser calls an internal API and then builds the page with JavaScript.

If you find that API, you can often request **JSON** instead of scraping HTML. This is usually much faster and more reliable. ([Stack Overflow][1])

---

# Step 5: Use Playwright or Selenium

If the page is rendered with JavaScript and protected by anti-bot systems, browser automation is generally the appropriate approach.

Example with Playwright:

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)

    page = browser.new_page()

    page.goto(
        "https://www.ambitionbox.com/list-of-companies?campaign=desktop_nav&page=1"
    )

    html = page.content()

    print(html[:1000])

    browser.close()
```

Since this uses a real browser engine, it succeeds on many sites where `requests` fails.

## Option 2: Use Playwright

Instead of

```python
requests.get(url)
```

use

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:

    browser = p.chromium.launch(headless=False)

    page = browser.new_page()

    page.goto(url)

    page.wait_for_timeout(5000)

    html = page.content()

    print(html)
```

Now the browser executes JavaScript.

The skeleton disappears.

Real content appears.

Then BeautifulSoup can parse it.

cards = soup.select(".job-card")
