Working with APIs is one of the most important skills in Machine Learning and Data Science because many real-world datasets come from web services instead of CSV files. APIs allow you to automatically collect fresh, structured data.

---

# What is an API?

**API (Application Programming Interface)** is a set of rules that allows one application to communicate with another.

Instead of downloading datasets manually, you ask a server for data.

```
Your Python Program
        │
   HTTP Request
        │
        ▼
    API Server
        │
 Processes Request
        │
        ▼
  JSON Response
        │
        ▼
 Python DataFrame
```

Example:

```
GET https://api.example.com/users
```

Server returns

```json
[
    {
        "id":1,
        "name":"John"
    },
    {
        "id":2,
        "name":"Alice"
    }
]
```

# Exception Handling

```python
try:
    response = requests.get(url)
    response.raise_for_status()

except requests.exceptions.HTTPError:
    print("HTTP Error")

except requests.exceptions.ConnectionError:
    print("Connection Error")

except requests.exceptions.Timeout:
    print("Timeout")

except Exception as e:
    print(e)
```

# Pagination

Large APIs split data into pages.

Example

```
Page 1

20 movies

Page 2

20 movies

Page 3

20 movies
```

Python

```python
import requests
import pandas as pd

all_movies = []

for page in range(1, 6):
    params = {"page": page}
    response = requests.get(url, params=params)
    data = response.json()["results"]
    all_movies.extend(data)

df = pd.DataFrame(all_movies)
```

# Rate Limits

Most APIs limit requests.

Example

```
100 requests/minute
```

If exceeded

```
429 Too Many Requests
```

Solution

```python
import time

for page in range(100):
    requests.get(url)
    time.sleep(0.5)
```

# Real ML Example (TMDb API)

```python
import requests
import pandas as pd

api_key = "YOUR_API_KEY"

all_movies = []

for page in range(1, 11):
    url = "https://api.themoviedb.org/3/movie/top_rated"

    params = {
        "api_key": api_key,
        "language": "en-US",
        "page": page
    }

    response = requests.get(url, params=params)
    response.raise_for_status()

    results = response.json()["results"]

    df_page = pd.DataFrame(results)[
        [
            "id",
            "title",
            "overview",
            "release_date",
            "popularity",
            "vote_average",
            "vote_count"
        ]
    ]

    all_movies.append(df_page)

df = pd.concat(all_movies, ignore_index=True)

print(df.head())
```

> **Note:** This uses `pd.concat()` on a list of DataFrames, which is the recommended replacement for the deprecated `DataFrame.append()` method.

# Best Practices

* Use `requests.Session()` when making many requests to reuse connections and improve performance.
* Store API keys in environment variables or configuration files, **not** directly in your code or public repositories.
* Always check the response status and handle exceptions gracefully.
* Use `params=` instead of manually building query strings.
* Respect API rate limits and terms of service.
* Cache responses when appropriate to avoid unnecessary repeated requests.
* Read the API documentation carefully to understand authentication, pagination, filtering, and response formats.
