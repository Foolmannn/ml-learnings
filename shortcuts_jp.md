 **Jupyter Notebooks (.ipynb) in VS Code**, there are two modes:

* **Edit Mode** – typing inside a cell.
* **Command Mode** – managing cells. Press **Esc** to enter Command Mode.

Here are the most useful shortcuts.

| Shortcut               | Action                                      |
| ---------------------- | ------------------------------------------- |
| **Enter**              | Edit current cell                           |
| **Esc**                | Command mode                                |
| **Shift + Enter**      | Run current cell and move to next           |
| **Ctrl + Enter**       | Run current cell and stay there             |
| **Alt + Enter**        | Run current cell and insert a new one below |
| **Ctrl + Alt + Enter** | Run all cells                               |

---

## Cell Management

| Shortcut                | Action               |
| ----------------------- | -------------------- |
| **A**                   | Insert cell above    |
| **B**                   | Insert cell below    |
| **X**                   | Cut selected cell    |
| **C**                   | Copy selected cell   |
| **V**                   | Paste cell below     |
| **Shift + V**           | Paste cell above     |
| **D D** (press D twice) | Delete current cell  |
| **Z**                   | Undo cell deletion   |
| **Shift + M**           | Merge selected cells |
| **Ctrl + Shift + -**    | Split cell at cursor |

---

## Change Cell Type

| Shortcut | Action        |
| -------- | ------------- |
| **Y**    | Code cell     |
| **M**    | Markdown cell |
| **R**    | Raw cell      |

---

## Running Cells

| Shortcut          | Action                            |
| ----------------- | --------------------------------- |
| **Shift + Enter** | Run and move to next              |
| **Ctrl + Enter**  | Run without moving                |
| **Alt + Enter**   | Run and create new cell           |
| **Run All**       | Toolbar button or Command Palette |

---

## Selection

| Shortcut            | Action                                    |
| ------------------- | ----------------------------------------- |
| **Shift + Up/Down** | Select multiple cells                     |
| **Ctrl + A**        | Select all text inside a cell             |

# Most Important Shortcuts to Memorize

1. **Esc** → Command Mode
2. **Enter** → Edit Mode
3. **Shift + Enter** → Run cell & go next
4. **Ctrl + Enter** → Run cell
5. **Alt + Enter** → Run & create new cell
6. **A** → New cell above
7. **B** → New cell below
8. **D D** → Delete cell
9. **Z** → Undo deleted cell
10. **M** → Markdown cell
11. **Y** → Code cell
12. **Ctrl + /** → Comment/uncomment
13. **Ctrl + Space** → Autocomplete
14. **Shift + Tab** → Function documentation
15. **Ctrl + Shift + P** → Command Palette
