# Machine Learning Development Life Cycle (MLDLC)

The **Machine Learning Development Life Cycle (MLDLC)** is a step-by-step process used to build, train, deploy, and maintain a machine learning model.

---

## 1. Problem Definition

### What happens?

* Understand the business problem.
* Define the goal of the ML system.
* Decide whether ML is actually needed.

### Example

A bank wants to predict whether a customer will default on a loan.

### Output

* Clear problem statement
* Success criteria

---

## 2. Data Collection

### What happens?

Gather relevant data from different sources.

### Sources

* Databases
* Websites
* Sensors
* Surveys
* APIs

### Example

For loan prediction:

* Customer age
* Income
* Credit score
* Loan amount
* Previous loan history

### Output

Raw dataset

---

## 3. Data Preparation (Preprocessing)

### What happens?

Clean and organize the collected data.

### Tasks

* Remove duplicates
* Handle missing values
* Correct errors
* Convert categorical data into numerical form
* Normalize/scale data

### Example

| Age | Income | Loan Status |
| --- | ------ | ----------- |
| 25  | 30000  | Paid        |
| ?   | 50000  | Default     |

Replace the missing age value with the average age.

### Output

Clean dataset ready for analysis

---

## 4. Exploratory Data Analysis (EDA)

### What happens?

Study the data to understand patterns and relationships.

### Tasks

* Create charts and graphs
* Find correlations
* Detect outliers
* Analyze distributions

### Example

Discover that customers with low credit scores are more likely to default.

### Output

Insights about the data

---

## 5. Feature Engineering & Feature Selection

### Feature Engineering

Create new useful features.

### Example

From:

* Date of Birth

Create:

* Age

### Feature Selection

Choose only important features.

### Example

For house price prediction:

* Area ✓
* Number of rooms ✓
* House color ✗

### Output

Relevant features

---

## 6. Split the Dataset

### What happens?

Divide data into:

| Dataset        | Purpose          |
| -------------- | ---------------- |
| Training Set   | Learn patterns   |
| Validation Set | Tune model       |
| Test Set       | Final evaluation |

Common split:

* 70% Training
* 15% Validation
* 15% Testing

### Example

1000 records:

* 700 train
* 150 validation
* 150 test

### Output

Separate datasets

---

## 7. Model Selection

### What happens?

Choose an appropriate algorithm.

### Examples

| Problem Type   | Algorithms                              |
| -------------- | --------------------------------------- |
| Classification | KNN, Decision Tree, Logistic Regression |
| Regression     | Linear Regression                       |
| Complex Tasks  | Neural Networks                         |

### Example

Predicting loan default → Logistic Regression

### Output

Selected model

---

## 8. Model Training

### What happens?

Train the model using training data.

### Example

The model learns:

* High income → lower default risk
* Low credit score → higher default risk

### Output

Trained model

---

## 9. Model Evaluation

### What happens?

Measure model performance using test data.

### Metrics

#### Classification

* Accuracy
* Precision
* Recall
* F1-score

#### Regression

* MAE
* MSE
* RMSE
* R²

### Example

Loan prediction model achieves:

* Accuracy = 92%

### Output

Performance report

---

## 10. Hyperparameter Tuning

### What happens?

Optimize model settings.

### Example

For KNN:

* K = 3
* K = 5
* K = 7

Choose the value giving the best performance.

### Output

Improved model

---

## 11. Model Deployment

### What happens?

Make the model available for real users.

### Example

Deploy loan prediction model on the bank's website.

When a customer applies:

* Model predicts loan risk instantly.

### Output

Production-ready system

---

## 12. Monitoring and Maintenance

### What happens?

Track performance after deployment.

### Reasons

* Data changes over time
* User behavior changes
* New patterns emerge

### Example

A spam detection model becomes less accurate because spammers use new techniques.

### Actions

* Retrain model
* Update features
* Improve performance

### Output

Reliable long-term model

---

## Real-Life Example: House Price Prediction

1. Define problem → Predict house prices.
2. Collect data → Area, rooms, location, age.
3. Clean data → Remove missing values.
4. Analyze data → Larger houses cost more.
5. Select features → Area, rooms, location.
6. Split data → Train/Test.
7. Choose model → Linear Regression.
8. Train model.
9. Evaluate accuracy.
10. Tune parameters.
11. Deploy on a real-estate website.
12. Monitor and retrain as market prices change.

### Exam Definition

**Machine Learning Development Life Cycle (MLDLC)** is a systematic process of developing an ML model, starting from problem definition and data collection through preprocessing, training, evaluation, deployment, and continuous maintenance to ensure accurate and reliable predictions.
