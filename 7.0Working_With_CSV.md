Working with **CSV (Comma-Separated Values)** files is one of the most common tasks in Machine Learning because most datasets are stored in CSV format. Before training any model, you usually need to load, inspect, clean, transform, and save CSV data.

---

# What is a CSV File?

A CSV file stores data in a tabular format.

Example (`students.csv`):

```csv
ID,Name,Age,Gender,Marks
1,Ram,20,Male,85
2,Sita,21,Female,92
3,Hari,19,Male,78
4,Gita,22,Female,88
```

Each row represents one observation (sample).

Each column represents one feature (attribute).

---

# Why CSV is Used in Machine Learning

CSV files are:

* Lightweight
* Human readable
* Easy to edit
* Supported by almost every programming language
* Supported by Pandas, NumPy, Scikit-Learn, TensorFlow, PyTorch

Typical ML workflow:

```
CSV File
      ↓
Load into Pandas
      ↓
Explore Data
      ↓
Clean Data
      ↓
Feature Engineering
      ↓
Train/Test Split
      ↓
Train ML Model
      ↓
Save Predictions
      ↓
CSV Output
```

```python

```

Read specific columns

```python
df = pd.read_csv(
    "data.csv",
    usecols=["Age", "Salary"]
)
```

Read in chunks

```python
for chunk in pd.read_csv(
    "data.csv",
    chunksize=10000

    print(chunk.head())
```

Useful for very large datasets.

# Common Preprocessing Before ML

Most ML projects follow these steps after loading a CSV:

```python
import pandas as pd

# Load data
df = pd.read_csv("data.csv")

# Inspect
print(df.head())
print(df.info())

# Remove duplicates
df.drop_duplicates(inplace=True)

# Handle missing values
df.fillna(df.mean(numeric_only=True), inplace=True)

# Separate features and target
X = df.drop("Target", axis=1)
y = df["Target"]
```

Then you typically encode categorical variables, scale numeric features, split into training and testing sets, and train a model.

---

# Best Practices

* Always inspect your data with `head()`, `info()`, and `describe()` after loading.
* Check for missing values (`isnull().sum()`) and duplicates before training.
* Avoid modifying the original dataset; work on a copy if needed.
* Use meaningful column names and correct data types.
* Save cleaned or transformed data with `to_csv(..., index=False)`.
* For large datasets, use `usecols`, `nrows`, or `chunksize` to reduce memory usage.
* Separate **features (`X`)** and the **target (`y`)** before model training.

Mastering these Pandas operations forms the foundation of nearly every machine learning workflow, as most real-world ML projects begin with loading, cleaning, and preparing data from CSV files.
