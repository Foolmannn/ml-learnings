# Feature Scaling in Machine Learning (Complete Guide)

Feature scaling is the process of **bringing numerical features to a similar scale** without changing their underlying relationships.

It is one of the most important preprocessing steps in machine learning because many algorithms assume that all features have comparable magnitudes.

---

# Why Do We Need Feature Scaling?

Imagine a dataset for house prices.

| Area (sq ft) | Bedrooms |
| ------------ | -------- |
| 1000         | 2        |
| 1500         | 3        |
| 2500         | 4        |
| 4000         | 5        |

Notice the ranges:

* Area: **1000–4000**
* Bedrooms: **2–5**

If we train some ML algorithms on this data, the **Area** feature dominates because its values are much larger.

The model may incorrectly think Area is much more important than Bedrooms simply because of its scale.

Feature scaling solves this problem.

---

# Example Without Scaling

Suppose we have two features.

| Height (cm) | Income ($) |
| ----------- | ---------- |
| 170         | 30000      |
| 180         | 50000      |
| 175         | 45000      |

Income is much larger.

Algorithms using distances will mostly compare **Income** while almost ignoring **Height**.

---

# Geometric Intuition

Imagine two people.

```
Person A

Height = 170
Income = 30000

Person B

Height = 180
Income = 35000
```

Euclidean distance

[
d=\sqrt{(180-170)^2+(35000-30000)^2}
]

[
=\sqrt{10^2+5000^2}
]

[
=\sqrt{100+25,000,000}
]

The height difference contributes almost nothing.

After scaling

```
Height
0.20
0.50

Income
0.30
0.60
```

Now both features contribute fairly.

---

# Which Algorithms Need Scaling?

## Scaling is Required

These algorithms are based on distance, optimization, or gradients.

* K-Nearest Neighbors (KNN)
* K-Means Clustering
* Support Vector Machines (SVM)
* Logistic Regression
* Linear Regression (especially with gradient descent)
* Neural Networks
* Principal Component Analysis (PCA)
* Linear Discriminant Analysis (LDA)

---

## Scaling is Usually Not Required

Tree-based algorithms split data based on thresholds, not distances.

* Decision Tree
* Random Forest
* XGBoost
* LightGBM
* CatBoost

Scaling usually has little or no effect on these models.

---

# Types of Feature Scaling

There are several common methods.

1. Standardization (Z-score)
2. Min-Max Scaling (Normalization)
3. Robust Scaling
4. Max Absolute Scaling
5. Unit Vector Scaling

Let's study each in detail.

---

# 1. Standardization (Z-score Scaling)

The most widely used scaling technique.

Formula

[
z=\frac{x-\mu}{\sigma}
]

where

* (x) = original value
* (\mu) = mean
* (\sigma) = standard deviation

After scaling:

* Mean = 0
* Standard deviation = 1

---

## Example

Original values

```
10
20
30
40
50
```

Mean

```
30
```

Standard deviation

```
14.14
```

Scaled values

```
-1.41
-0.71
0
0.71
1.41
```

Notice

* centered around 0
* values are comparable

---

## Python

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

X_scaled = scaler.fit_transform(X)
```

---

## What does fit() do?

```python
scaler.fit(X)
```

Calculates

* mean
* standard deviation

---

## What does transform() do?

Uses the calculated statistics.

[
x=\frac{x-\mu}{\sigma}
]

---

## Why fit_transform()?

```python
X_train_scaled = scaler.fit_transform(X_train)
```

Equivalent to

```python
scaler.fit(X_train)

X_train_scaled = scaler.transform(X_train)
```

---

## Test Data

Never do

```python
scaler.fit_transform(X_test)
```

Correct

```python
X_test_scaled = scaler.transform(X_test)
```

The test data must use the **same mean and standard deviation** learned from the training data to avoid data leakage.

---

[

]

Maps data into

```

```

```

```

```

```

```

```


---

## Python

```python
from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler()

X_scaled = scaler.fit_transform(X)
```

---

## Advantages

Very intuitive.

Everything lies between

```

```

---

## Disadvantage

Sensitive to outliers.

Example

```
20
25
30
35

```

Now nearly every normal value becomes very close to 0.

---

# 3. Robust Scaling

Uses

* Median
* Interquartile Range (IQR)

Formula

[
\frac{x-\text{Median}}{\text{IQR}}
]

where

[
IQR=Q3-Q1
]

---

## Why?

Median is much less affected by outliers.

Example

```
20
25
30
35
1000
```

Mean changes dramatically.

Median remains

```
30
```

---

## Python

```python
from sklearn.preprocessing import RobustScaler

scaler = RobustScaler()

X_scaled = scaler.fit_transform(X)
```

---

## Best for

Data containing many outliers.

---

# 5. Unit Vector Scaling (Normalization)

Each row is scaled so its vector has length 1.

Formula

[
x=\frac{x}{||x||}
]

where

[
||x||=\sqrt{x_1^2+x_2^2+\cdots}
]

---

Example

Vector

```
(3,4)
```

Length

```
5
```

Scaled

```
(0.6,0.8)
```

---

Python

```python
from sklearn.preprocessing import Normalizer

normalizer = Normalizer()

X = normalizer.fit_transform(X)
```

This is often used for text data (e.g., TF-IDF vectors) and cosine similarity.

# Which Scaling Method Should You Use?

| Situation                          | Best Choice                    |
| ---------------------------------- | ------------------------------ |
| Normally distributed data          | StandardScaler                 |
| Neural networks                    | StandardScaler or MinMaxScaler |
| Data with many outliers            | RobustScaler                   |
| Sparse matrices                    | MaxAbsScaler                   |
| Text vectors / cosine similarity   | Normalizer                     |
| Features already on similar scales | Often no scaling needed        |

# Using a Pipeline (Recommended)

Pipelines ensure that preprocessing is applied consistently during training and prediction.

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

pipe = Pipeline([
    ("scaler", StandardScaler()),
    ("model", LogisticRegression())
])

pipe.fit(X_train, y_train)

predictions = pipe.predict(X_test)
```

# Common Mistakes

### 1. Scaling before train-test split ❌

```python
scaler.fit_transform(X)
```

Then splitting the data leaks information from the test set into the training process.

Correct:

```python
X_train, X_test, y_train, y_test = train_test_split(X, y)

scaler.fit(X_train)

X_train = scaler.transform(X_train)
X_test = scaler.transform(X_test)
```

---

### 2. Scaling categorical features ❌

Don't scale features like:

```
Gender
City
Country
```

These should be encoded first (e.g., one-hot encoding) and are generally not standardized.

---

### 3. Fitting on test data ❌

Never do:

```python
scaler.fit(X_test)
```

The test set should only be transformed using parameters learned from the training set.

# StandardScaler vs MinMaxScaler

| Feature                      | StandardScaler               | MinMaxScaler                      |
| ---------------------------- | ---------------------------- | --------------------------------- |
| Output range                 | Unbounded                    | Usually 0 to 1                    |
| Uses                         | Mean & standard deviation    | Minimum & maximum                 |
| Outlier sensitivity          | Moderate                     | High                              |
| Preserves distribution shape | Yes                          | Yes (linearly rescales)           |
| Good for                     | Linear models, SVM, PCA, KNN | Neural networks, bounded features |

---

# Interview Questions

### Q1. Why don't Decision Trees require scaling?

Decision trees compare feature values to thresholds (e.g., `Age < 30`). Multiplying a feature by a constant changes the threshold but not the order of the data, so the tree structure remains essentially unchanged.

### Q2. What is data leakage in scaling?

Data leakage occurs when statistics from the test set (such as its mean or maximum value) are used during preprocessing. This gives the model information it should not have during training and can lead to overly optimistic evaluation results.

### Q3. Which scaler is best for outliers?

`RobustScaler`, because it uses the median and interquartile range instead of the mean and standard deviation.

### Q4. Can you scale after one-hot encoding?

Yes. Numeric features are usually scaled, while one-hot encoded columns (0s and 1s) are often left unchanged. A `ColumnTransformer` is commonly used to apply different preprocessing steps to different column types.

# Summary

| Scaler         | Formula                        | Output              | Best Use Case                      |         |             |
| -------------- | ------------------------------ | ------------------- | ---------------------------------- | ------- | ----------- |
| StandardScaler | ((x-\mu)/\sigma)               | Mean = 0, Std = 1   | Linear models, SVM, PCA, KNN       |         |             |
| MinMaxScaler   | ((x-\min)/(\max-\min))         | Usually 0–1         | Neural networks, bounded features  |         |             |
| RobustScaler   | ((x-\text{median})/\text{IQR}) | Centered on median  | Data with outliers                 |         |             |
| MaxAbsScaler   | (x/\max(                       | x                   | ))                                 | -1 to 1 | Sparse data |
| Normalizer     | (x/|x|)                        | Unit-length vectors | Text processing, cosine similarity |         |             |

The key takeaway is that **feature scaling does not change the underlying information in your data—it only changes the numerical representation**. Choosing the right scaling method depends on your data distribution, the presence of outliers, and the machine learning algorithm you plan to use.
